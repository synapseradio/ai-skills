---
name: find-leverage
description: Use when effort is spread across a system and results stay small, or to choose where to intervene. Finds the point where a small change shifts the whole system, and names the single best intervention.
---

The subject is the system or recurring problem named in the request.

## Steps

### 1. Trace the feedback loops

Name the loops that run through the system, reinforcing and balancing, and what flows around each.

### 2. Locate bottlenecks

Name where things get stuck: the points whose capacity sets the pace of everything after them.

### 3. Find amplification points

Name where one action affects many outcomes.

### 4. Spot compounding

Name what builds on itself over time, in either direction.

### 5. Identify root causes

Name the causes that each produce many symptoms, and list the symptoms each one accounts for.

### 6. Evaluate leverage ratio

List the candidate interventions at the points found. For each, set what it shifts against the effort to keep it going. Favor points where a small change shifts the whole system over points that need constant effort to maintain.

### 7. Name the intervention

Name the single highest-leverage intervention, what it needs to be set up, and the first sign that it is failing.

## Return

Return the loops, the points found in steps 2 to 5, the candidates compared, and the one intervention. Tie each loop and point to something observed in the system, and mark a link you inferred as a guess the people in the system could confirm. The run ends at the named intervention.

A return on a shared flat where the dishes never get done and two rotas have died, cut to one loop, one root cause, and the intervention:

<example>

- **The free-rider loop (reinforcing).** One person leaves a dish. Another sees it and leaves theirs. A dish in a pile has no visible owner, so nobody can check what the others do, and the belief gets read in the worst direction.
- **Root cause.** A dish in the sink belongs to nobody. That accounts for the free-rider loop, both failed rotas, and the belief that the others do not wash.
- **Intervention.** Give each resident one plate, one bowl, and one mug, and put the rest away. Setup: wash the pile once and box the spares. First sign of failure: a cooking pot left in the sink.

</example>
