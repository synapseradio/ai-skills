### 1. Trace the feedback loops

Name the loops that run through the system, reinforcing and balancing, and what flows around each.

### 2. Locate bottlenecks

Name where things get stuck: the points whose capacity sets the pace of everything after them.

### 3. Find amplification points

Name where one action affects many outcomes.

### 4. Spot compounding

Name what builds on itself over time, in either direction.

### 5. Identify root causes

Name the causes that each produce many symptoms, and list the symptoms each one accounts for.

### 6. Evaluate leverage ratio

List the candidate interventions at the points found. For each, set what it shifts against the effort to keep it going. Favor points where a small change shifts the whole system over points that need constant effort to maintain.

### 7. Name the intervention

Name the single highest-leverage intervention, what it needs to be set up, and the first sign that it is failing.
