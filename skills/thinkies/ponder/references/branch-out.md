### 1. Fix the starting point

State the starting point and the one decision or constraint that could be altered. Hold everything else fixed, so the branches can be compared.

### 2. Generate divergent directions

Produce several directions that differ in kind. Two directions differ in kind when they answer the altered decision differently; where two differ only in degree or detail, merge them into one.

### 3. Make each branch concrete

For each branch, say what would differ in practice and the trade-off that only this branch carries.

### 4. Map the divergence

Name the choices at which the paths split, earliest first. Say which splits are hard to reverse and which branches could later recombine.
