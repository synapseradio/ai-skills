### 1. Identify the current frame

Name the frame the subject arrived in: whose seat it is seen from, and what that seat takes the goal to be.

### 2. Choose contrasting perspectives

Choose a few — different stakeholders, disciplines, time horizons, or levels of expertise. Pick ones that differ from the current frame and from each other. Where the request names the perspectives, use those.

### 3. Inhabit each fully

What does it assume, prioritize, and protect? Use "I" statements from within each frame.

### 4. Find the blind spots

Locate what each perspective sees that the others miss, the starting frame included.

### 5. Note the clashes

Note where perspectives genuinely clash: where giving one what it wants costs another. Set apart the clashes that dissolve once both sides are stated.

### 6. Return with insight

Return with the insight that no single frame would have produced alone, and say what follows from it for the subject.
