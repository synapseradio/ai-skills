---
name: excavate-assumptions
description: Use when a framing, plan, or argument rests on things nobody has said aloud. Brings its
  unstated assumptions into view and singles out for testing the ones that matter most and are least
  certain.
---

The subject is the claim, plan, or framing named in the request, or the one the conversation is working from.

## Steps

### 1. List every assumption

List what the current framing takes for granted without saying so. Word each assumption as a statement that could be false.

### 2. Dig at each level

Read the framing again at four levels, and add what each turns up:

- **Semantic**: what must be true for this to be meaningful
- **Pragmatic**: what must be true for this to be worth saying
- **Logical**: what must hold for the reasoning to work
- **Framework**: what worldview this assumes

### 3. Rate importance and certainty

Rate each on importance (how much the conclusion depends on it) and certainty (how well-supported it is), with the ground for each rating in a few words.

### 4. Focus the attention

Carry forward the assumptions that are both highly important and highly uncertain. Set the rest aside by name.

### 5. Test each

For each assumption carried forward, answer "what evidence would disprove this?" and "what if the opposite were true?"

## Return

Return the assumptions, numbered, with their ratings, and for each one carried forward the evidence that would disprove it and what follows if it is false. Close with the check to run first: the cheapest one whose result would change the most. The run ends there.
