### 1. Pause the inquiry

Pause the current line of inquiry, and state the question as it stands, in its own words.

### 2. Ask why this question

Ask "Why is this the question we are asking?" and "What question should we be asking instead?" Name the concern behind the question, and a few candidate questions that aim elsewhere.

### 3. Probe its assumptions

List what must be true for this to be the right question, and name the assumption that carries the most.

### 4. Check for drift

Compare the question with the core concern, and name each place where its wording has moved the target.

### 5. Sharpen or reframe

If well-aimed, sharpen it: press for precise definitions, concrete examples, clear boundaries. If not, reframe and redirect: state the new question and what it aims at that the old one missed.
