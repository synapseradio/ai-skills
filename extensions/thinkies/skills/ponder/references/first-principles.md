### 1. Identify the convention

State the current belief and the conventional approach built on it, taken from the context of your task and the user's request. List the components the approach is made of.

### 2. Question every component

For each component, ask whether it is a fundamental truth or an assumption from convention, analogy, or authority. Say where each came from.

### 3. Keep what survives

Keep only what survives the questioning: what would hold whatever the convention said. Hold a claim you cannot back as a hypothesis, with the test that would settle it.

### 4. Reason up

Given only the surviving fundamentals, build what follows from them, as someone would who had never met the convention.

### 5. Compare with convention

Set the rebuilt version beside the conventional one. Each difference marks a constraint as real, because it survived, or inherited, because it did not.

### 6. Open new possibilities

Name the possibilities that open when the inherited constraints are removed.
