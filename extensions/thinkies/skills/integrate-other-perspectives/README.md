# integrate-other-perspectives

Combine viewpoints into a coherent whole. Finds points of contact, addresses tensions, builds the synthesis, and tests it for coherence.

## It helps when

- Several people want different things and the choice has shrunk to "whose wins".
- Two positions look opposed and you suspect they answer different questions.
- You need one plan that keeps what matters from each view, and you want to be honest about what it loses.

## What you'll get

Each view in its own terms and what it leaves open, where the views touch, which tensions are real and which only look real, a synthesis with the principle that organises it, a check that it keeps what matters to each person (with the losses named), and the gaps and questions still open.

A run on a Saturday outing where an eight-year-old wants the beach ("there are crabs"), a parent wants the museum ("it's free and it might rain"), and a grandparent wants "somewhere with a bench and a proper cup of tea", trimmed ([full run](https://github.com/synapseradio/ai-skills/blob/main/examples/thinkies/integrate-other-perspectives/beach-or-museum.md)):

> **What the tensions reveal.** Only one tension is about the places themselves: weather. The rest are about the arrangement inside a place: distance from bench to crabs, and where tea comes from.
>
> […]
>
> **The organizing principle.** Treat each person's statement as a requirement on the day, not as a vote for a place.
>
> […]
>
> - Child: kept in full on a dry day. Kept only as a substitute (a crab hunt indoors) on a wet day. That is a real loss, and the plan says so.

## Install

```bash
npx skills add https://github.com/synapseradio/ai-skills
```

Or copy `skills/thinkies/integrate-other-perspectives/` into `~/.claude/skills/integrate-other-perspectives/`.

## Usage

```
/integrate-other-perspectives <perspectives or viewpoints to integrate>
```
