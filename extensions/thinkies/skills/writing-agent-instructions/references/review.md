# Review

Entered when an instruction exists and the question is whether it works, or when an original and a rewrite exist and the question is what the rewrite lost. Nothing is changed in this mode; the output is findings.

## One instruction, no rewrite

1. Write its four parts out as they stand: domain, mapping, expansion rule, anchor. Mark each part the text leaves unstated.
2. Run Closure, Visibility, Edge, Two readings, and Terms.
3. Report each unstated part as a decision the reader must close on its own, and each failed check with its evidence, in the skill's Output shape with the Generator section holding the parts as found.

## An original and a rewrite

1. Run Tokens first. A missing token is a defect whatever the rewrite's accounting says.
2. Build the case table from the original, one row per line, as Compress step 1 describes.
3. Take the rewrite's generator as given and run Trace yourself over that table. Where the rewrite carries its own accounting, compare your result column with it. Any row where the two expansions differ is a finding in itself, since two readers already expand it differently, before a third reader meets it.
4. Run Edge, Two readings, Terms, and Size on the rewrite.
5. Emit the skill's Output shape, with the rows from step 3 that differ under an added heading "Disagreements", and every line the rewrite neither reproduces nor keeps under Dropped.
