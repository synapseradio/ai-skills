---
name: consider-alternatives
description: Use when one explanation for an observation was accepted early, as in diagnosis or root-cause work. Raises rival explanations for the same evidence and names the test that would tell them apart.
---

The subject is the observations named in the request and the explanation currently given for them.

## Steps

### 1. State the current explanation

State the current explanation and the evidence for it. Name each observation it strains to cover, since whatever is true must explain those too.

### 2. Generate alternatives

Vary the mechanism, the scope, the timing, and the direction of causation. Combine multiple causes. Question whether the pattern is coincidence.

### 3. Make each alternative concrete

For each, describe how it would work and what it predicts that someone could observe.

### 4. Identify distinguishing tests

Name the evidence that would separate one explanation from another: an observation on which two of them predict differently. Put first the test that rules out the most explanations.

## Return

Return the current explanation with its evidence, the alternatives with their predictions, and the tests in order, each with the explanations its outcomes would remove. Where a test's result is already in hand, apply it and say which explanations remain. The run ends at the ordered tests, and names a winner only where the results in hand leave one explanation standing.
